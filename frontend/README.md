# Jogo Mario - Frontend

Frontend do jogo desenvolvido para a atividade acadêmica de Git e GitHub.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js

## Execução

Dentro desta pasta, execute:

```bash
npm install
npm run dev
```

O comando `npm run dev` inicia um servidor local para o jogo.

## Controles

- `←` e `→`: movimentar o personagem
- `Espaço`: pular

## Objetivo do jogo

Colete as moedas, evite o inimigo e alcance a bandeira para vencer.
