# Jogo Mario

## Descrição

Projeto de um jogo inspirado no universo do Mario, desenvolvido como atividade acadêmica para praticar Git e GitHub.

## Objetivo

Desenvolver e organizar o projeto do Jogo Mario, utilizando Git para controle de versões e GitHub para organização e compartilhamento do projeto.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js

## Instalação

Entre na pasta frontend e instale as dependências:

cd frontend
npm install

## Execução

Para executar o projeto:

npm run dev
