# Requisitos do Jogo Mario

## 1. Objetivo

Desenvolver um jogo inspirado no universo do Mario, utilizando tecnologias web e aplicando conceitos de controle de versão com Git e GitHub.

## 2. Requisitos funcionais

### RF01 — Movimentação
O jogador deve conseguir movimentar o personagem durante o jogo.

### RF02 — Pulo
O jogador deve conseguir fazer o personagem pular para evitar obstáculos.

### RF03 — Obstáculos
O jogo deve apresentar obstáculos que o jogador precisa evitar.

### RF04 — Colisão
O jogo deve detectar quando o personagem colidir com um obstáculo.

### RF05 — Game Over
Ao ocorrer uma colisão, o jogo deve interromper a partida e apresentar a imagem de Game Over.

### RF06 — Música
O jogo deve possuir música de fundo durante a partida.

### RF07 — Pontuação
O jogo deve possuir uma estrutura preparada para controle de pontuação.

## 3. Requisitos não funcionais

### RNF01 — Navegador
O jogo deve funcionar em navegador web.

### RNF02 — Tecnologias
O projeto deve utilizar HTML, CSS, JavaScript e Node.js.

### RNF03 — Organização
Os arquivos do jogo devem permanecer dentro da pasta `frontend`.

### RNF04 — Controle de versão
O projeto deve ser versionado utilizando Git e hospedado no GitHub.

## 4. Controles

- **Teclado:** pressionar uma tecla para fazer o Mario pular.
- **Objetivo:** evitar os obstáculos e continuar a partida.
